# atsStoneGenerator

The plugin allows to craft the block generator block, that will generate block of stone above itself as in infinite loop.

To get the generator just put one piston in the middle of 3x3 crafting table and 8x stone around it. Material of generated block, as far as the generator's one, including name and lore, can be set in the `config.yml` file. 

You can download the plugin from here: [atsStoneGenerator](https://ats.andret.eu/atsBlockGenerator.jar)
